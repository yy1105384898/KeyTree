# WebDAV 同步

1. 先备份密码库，在 **设置 → 同步** 填写 HTTPS `.kdbx` 文件地址、用户名和应用专用密码。
2. 保存配置，点击“测试连接”，再点击“立即同步”。
3. 换设备编辑前后各同步一次。也可开启“锁定时自动同步”：先锁定，再上传已保存密文；远端有变化则停止，解锁后手动同步合并。没有定时同步。

**坚果云：** 先上传同一份 KDBX，再填写文件地址，例如 `https://dav.jianguoyun.com/dav/KeyTree/vault.kdbx`。使用应用专用密码，不使用分享链接。

不要同时用云盘客户端同步同一本地文件。手机需另选兼容客户端，密钥文件单独安全传递；真实服务兼容性仍需验证。

## S3 兼容存储

在同步设置选择 S3，分别填写 Endpoint、Bucket、对象路径、区域、Access Key ID 和 Secret Access Key。使用 Path-style 地址；Endpoint 不含路径。内网 IP 可使用 HTTP，但通信不加密。R2 的区域一般填写 `auto`。每个密码库保存一个同步目标，切换类型会替换该库原有配置，需重新填写凭据。

应用使用 AWS Signature Version 4，并以读取返回的强 ETag 执行条件上传；首次创建使用 `If-None-Match: *`。服务端必须正确支持对应条件写入，否则不能安全用于多端同步。先用测试库验证连接、首次创建和冲突，再用于正式密码库；兼容性因服务商而异。当前不支持临时凭据的 session token。

遇到冲突先备份、重新同步，不要强行覆盖。本地保存不等于已上传，连接测试也不代表同步完成。
